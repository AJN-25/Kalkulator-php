# Modern Calculator Web App

A simple modern calculator web application built using HTML, CSS, JavaScript, and PHP.  
This project was created as a practice project to start coding again and improve frontend + basic interactive programming skills.

## Features

- Basic arithmetic operations
  - Addition (+)
  - Subtraction (-)
  - Multiplication (×)
  - Division (÷)

- Modern calculator UI
- Keyboard support
- Real-time calculation
- Clear display button
- Responsive layout
- Calculation history
- Clear history feature

## Technologies Used

- HTML
- CSS
- JavaScript
- PHP
